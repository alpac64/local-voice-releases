# Local Voice downloads

Free, local dictation and meeting notes for Mac. Nothing you say leaves your Mac.

- **Download:** the latest DMG is under Releases, or at https://local-voice-site.vercel.app/download
- **Requirements:** Apple silicon Mac, macOS 14.4 or later.
- **Updates:** installed copies check `appcast.xml` from the latest release once a day and install only when you agree.

Source lives in a separate repository; this one exists to serve releases.
